# Lumen Guard's allowlist (stage G2, decision 11): on the B9 (OLED55B9PUA,
# webOS 4.10.2, US store) a name resolves only when a rule here, or in the
# owner's own file, allows it. Everything else gets 0.0.0.0 or :: from Guard.
#
# This is the public, generic list: the Content Store, DRM, the apps the
# family pays for, casting, and Lumen's own probes, each with its reason. The
# owner's additions (what else the household uses) stay off this repository,
# on the TV and in the owner's backups (decision 12): tools/guard.sh owner.
#
# tools/store-safe-check.sh fails if any of these is sinkholed, and Guard
# itself refuses to block while its rules would block the store, DRM or the
# paid apps (rules.rs, MUST_RESOLVE).
#
# Format: one rule per line; text after # is a comment.
#   name     matches the name and every name under it (netflix.com matches
#            www.netflix.com but not notnetflix.com)
#   =name    matches that exact name only
# A more specific carve-out (carve-outs.txt, imported/) still blocks a name
# under one of these suffixes; an exact rule here beats any list's suffix.
#
# Sources: "seed" is the Phase 1 research (docs/roadmap.md, decision 5) and
# the owner's must-keep list (2026-10-20); "G1" marks names Guard logged on
# the B9 in its week, 2026-10-31 06:31Z to 2026-11-08 20:29Z (8,211 lookups
# of 94 names). Seed suffixes the week didn't show stay until a log shows
# what is under them: the store and the paid apps come first.
